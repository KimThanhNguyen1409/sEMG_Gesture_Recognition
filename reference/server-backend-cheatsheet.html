C Inference Server Backend Cheatsheet

Tóm tắt toàn bộ cấu trúc dữ liệu, hàm xử lý và định dạng gói tin MQTT trong Server/src/main.c.

1. Bảng Ánh xạ 5 Bước Xử lý (5-Stage Pipeline)

Giai đoạn Hàm trong main.c / inc/ Đầu vào Đầu ra
1. MQTT Rx on_mqtt_message() Topic semg/v1/+/features (QoS 0) Chuỗi JSON thô msg->payload
2. Zero-Malloc Parse parse_feature_payload() Chuỗi JSON {"seq":1,"f":[...]} int seq + raw_features[15]
3. Z-Score Norm semg_normalize_features() raw_features[15], FEATURE_MEAN, FEATURE_STD norm_features[15]
4. MLP Inference ml_runtime_infer() norm_features[15] Xác suất 4 lớp probs[4]
5. Vote & Publish post_process_vote() + mosquitto_publish() probs[4] (Ngưỡng 0.75, cửa sổ 3) Topic semg/v1/control/gesture (QoS 1)

2. Bảng Mã Cử chỉ (Gesture Classes)

gesture_id Nhãn (label) Thư mục Dataset gốc Hành vi trên Server
0 RESTING 1st_Gesture_Resting Trạng thái nghỉ mặc định khi conf < 0.75
1 FIST 2nd_Gesture_Fist Nắm chặt bàn tay
2 OPEN_HAND 4th_Gesture_Open_Hand Xòe căng bàn tay
3 POINTING 7th_Gesture_Pointing Chỉ ngón trỏ

3. Định dạng Bản tin MQTT Chuẩn
